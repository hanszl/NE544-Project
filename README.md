# NE544 Project

This repository contains coursework, simulations, and analysis for NE544 (Reactor Physics).  
All work is performed in a reproducible WSL-based environment using Git, Python, and OpenMC.

## Project Structure
- `input/` — OpenMC input decks
- `scripts/` — Python scripts for running and analyzing simulations
- `notebooks/` — Jupyter notebooks for visualization and analysis
- `results/` — Output data, plots, and processed results
- `docs/` — Reports, writeups, and supporting material

## Environment
This project uses:
- WSL2 (Ubuntu)
- Python 3.x
- OpenMC
- Git + SSH for version control

## Goals
- Build and run OpenMC simulations
- Analyze neutron transport behavior
- Produce reproducible results for NE544 assignments and projects
